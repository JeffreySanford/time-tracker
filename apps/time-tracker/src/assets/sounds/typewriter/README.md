# Typewriter Ambient Sound

This directory should contain the ambient background music for the typewriter animation.

## Required File

- `ambient.mp3` - Ambient jazz/background music that plays during typing animations

## Audio Specifications

- **Format**: MP3
- **Duration**: 30-60 seconds (loopable)
- **Style**: Cool jazz, ambient, or relaxing background music
- **Volume**: Should be subtle/quiet enough to not interfere with work
- **Bitrate**: 128kbps or higher
- **Sample Rate**: 44.1kHz

## Suggested Audio Sources

1. **Free Options**:
   - Freesound.org (CC licensed ambient jazz)
   - YouTube Audio Library
   - Pixabay Audio
   - Zapsplat (free tier)

2. **AI Generated**:
   - Suno AI
   - Udio
   - AIVA
   - Soundraw

3. **Sample Libraries**:
   - Jazz piano loops
   - Ambient coffee shop sounds
   - Soft instrumental background music

## Example Search Terms

- "ambient jazz piano loop"
- "coffee shop background music"
- "subtle jazz ambient"
- "typing atmosphere music"
- "work focus jazz background"

## Implementation

Once you have the audio file, simply place it in this directory as `ambient.mp3` and the application will automatically use it instead of the fallback.
